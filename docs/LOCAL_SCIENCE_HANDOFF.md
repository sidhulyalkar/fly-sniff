# Local science handoff

This workflow is designed so the owner of the repository can generate the evidence needed for remote scientific review without another coding agent running on the same machine.

The handoff is descriptive. It does not promote structural connectivity into physiological or behavioral function.

## 1. Verify the checkout

```bash
conda deactivate 2>/dev/null || true
source .venv/bin/activate
python -m pip install -e '.[malecns,dev]'

which python
python --version
git branch --show-current
git rev-parse HEAD
git status --short
ruff check src tests
pytest -q
```

Record the exact git SHA. Scientific artifacts generated by a dirty checkout should be treated as development artifacts until the diff is reviewed.

## 2. Regenerate the corrected structural corridor

Do not overwrite the historical v0 trace. The science-v1 tracer changed saved-edge semantics so that exported edges obey the same `min_weight` threshold used during graph discovery.

```bash
fly-sniff-trace \
  data/raw/body-annotations-male-cns-v1.0.feather \
  data/raw/connectome-weights-male-cns-v1.0-minconf-0.5.feather \
  --source 'ORN' \
  --source '^Or' \
  --source '^Ir' \
  --target '^DNa02' \
  --max-hops 6 \
  --min-weight 5 \
  --fanout 30 \
  --output data/cache/staged-route-v1
```

## 3. Audit the trace

```bash
mkdir -p results/trace

fly-sniff-audit-trace \
  data/cache/staged-route-v1 \
  --output results/trace/staged-route-v1-audit.json
```

The audit checks:

- node/provenance identity closure;
- edge endpoint closure;
- retained source/target seed closure;
- the configured minimum edge weight;
- the bounded hop constraint;
- trace-report count consistency;
- depth distributions;
- edge-weight and degree distributions;
- strongest structural hubs;
- graph-depth transition geometry.

These properties are structural only.

## 4. Build the complete local handoff

```bash
mkdir -p results/handoff

fly-sniff-science-handoff \
  data/raw/body-annotations-male-cns-v1.0.feather \
  data/raw/connectome-weights-male-cns-v1.0-minconf-0.5.feather \
  --trace-dir data/cache/staged-route-v1 \
  --output results/handoff/science-handoff-v1.json
```

The JSON contains:

- Python/platform/git identity and dirty-file list;
- SHA-256 and byte size of the raw annotation, raw weight, and derived trace artifacts;
- annotation schema and high-frequency annotation values;
- separate match counts/examples for `ORN`, `^Or`, and `^Ir`;
- overlap counts between those source hypotheses;
- exact/family annotation matches for `FB5AB`, `PFNa`, `PFNm`, `PFNp`, `hDeltaC`, `PFL3`, and `DNa02`;
- corrected trace report and full structural audit;
- dominant neuron types at each forward graph depth;
- edge counts and summed structural weight for every forward-depth transition;
- strongest type-to-type structural connection aggregates;
- exact anchor populations retained in the traced corridor, including their graph depths and seed flags.

This is the preferred file to upload or paste into a review chat.

## 5. Small terminal summary

For a compact first message, run:

```bash
jq '{
  protocol,
  runtime,
  input_hashes: (.inputs | map_values(.sha256)),
  olfactory_seed_hypothesis,
  trace_counts: .trace_audit.counts,
  trace_checks: .trace_audit.checks,
  anchor_corridor_membership: (
    .anchor_corridor_membership
    | map_values({
        annotation_population_count,
        retained_in_corridor_count
      })
  )
}' results/handoff/science-handoff-v1.json
```

If that output is too long, the CLI itself already prints a concise summary after writing the JSON.

## 6. Files worth sharing if deeper review is needed

The highest-value bundle is:

```text
results/handoff/science-handoff-v1.json
data/cache/staged-route-v1/trace_report.json
results/trace/staged-route-v1-audit.json
data/cache/staged-route-v1/path_provenance.csv
```

`nodes.parquet` and `edges.parquet` are useful for deeper local analysis but can be much larger. Upload them only when exact body-ID or edge-level follow-up is needed.

## 7. Interpretation boundary

A retained body ID means only that it lies in the configured bounded structural corridor under the current search procedure. A high structural weight, central graph position, or membership in a named cell type does not establish odor response, activity timing, causal navigation relevance, or physiological sign.
