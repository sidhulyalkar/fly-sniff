# Who Farted? showcase v2

## Public question

> We gave a fruit-fly navigation model a smell to follow. The candidate circuit is constrained by exact MaleCNS connectome structure. Can the eventually qualified intact wiring find the source better than a matched scramble?

The joke is the wrapper. The evidence boundary is the product.

## Two releases, not one overclaimed video

### Release A: structure teaser

This can ship before behavioral MaleCNS qualification.

Allowed:

- one shared room with six suspects and an audience-visible odor plume;
- exact MaleCNS body-ID-resolved circuit structure in a compact inset;
- development proxy trajectory from a hashed recording;
- the already-qualified restricted steering result as separately labeled `MODELED ACTIVITY` only when the recording actually contains that modeled state;
- labels such as `CANDIDATE MALECNS STRUCTURE` and `DEVELOPMENT PROXY`.

Not allowed:

- `THE CONNECTOME FOUND HIM`;
- `REAL WIRING WINS`;
- measured-firing language;
- animated activity through FB5AB/PFN/hDeltaC/hDeltaG before E002b is sealed.

### Release B: qualified hero

This becomes the main social clip only after signed integration, sensory/wind role sealing, matched degree-preserving rewires, equal compute budgets, frozen held-out episodes, lesions, and paired cohort statistics pass their predeclared gates.

Then the public question becomes the stronger and simpler:

> REAL CONNECTOME vs SCRAMBLED WIRING. Same smell. Same room. Who finds the farter?

## Visual semantics

### Measured connectivity

Static or gently highlighted edges. Thin, restrained lines. Exact graph edges may brighten when the story focuses on a route, but the animation must not imply that a synapse was observed firing.

Current body-ID-resolved foreground populations:

```text
FB5AB
PFNa / PFNm / PFNp
hDeltaC
hDeltaG
PFL3 / PFL2
DNa03 / LAL010
DNa02
```

The compact neural panel should group many body IDs by population for readability while retaining an optional developer/debug mode that exposes body IDs and exact weights.

### Modeled activity

A glow, fill level, or small traveling pulse may be used only for state that is present in the immutable episode recording. It must be labeled `MODELED ACTIVITY` on screen.

Never derive a fresh neural trajectory inside the renderer. Renderer input is data, not a simulator.

### Behavior

Use the recorded antenna signals, body-frame airflow, controller action, fly pose, and path. The fly never receives source coordinates, culprit identity, or the audience's plume visualization.

## Fly glyph

Replace the triangle with a small readable fly:

- oriented abdomen/thorax axis from recorded heading;
- two wings kept visually quiet;
- two antennae whose brightness/size is driven by the recorded left/right odor values;
- a short nose/heading indicator only in debug mode;
- no fake neural glow inside the animal.

The antenna animation gives the audience an immediate causal link between the visible plume and what the controller actually senses.

## Plume

The viewer should understand the plume in under a second.

When a recording contains a complete plume snapshot, render the recorded density field or recorded puff set faithfully. When the snapshot is sampled/incomplete, use particles or a clearly approximate preview. Never reconstruct a smooth exact field from truncated data and present it as the simulation truth.

Visually prefer a soft translucent body plus a few brighter local wisps over hundreds of equally salient dots.

## Circuit-strip topology

Use anatomical columns only where the MaleCNS instance metadata provides them.

Current release metadata supports column parsing for nearly all PFNa/PFNm cells and all hDeltaC, hDeltaG, PFL3, and PFL2 cells. PFNp lacks usable column labels in this artifact, so PFNp remains a pooled node instead of receiving invented column positions.

The topography audit must remain descriptive. Column labels are not wind angles. hDeltaC physiology is known to be fly-specific, so no behavioral direction may be assigned from a column number alone.

## Scientific build order

1. Preserve the blocked sign-audit v1 as evidence that the local annotation feather lacks transmitter fields.
2. Run sign-audit v2 against the pinned external Cell Type Explorer transmitter authority.
3. Run the descriptive topography audit.
4. Freeze E002b before viewing behavioral outcomes.
5. Build a signed mechanistic integration scaffold across every already-fixed structural threshold (1, 3, 5, 10), rather than selecting a threshold because it performs best.
6. Inject abstract mechanistic FB5AB/PFN drives first. Do not call them odor/wind sensory inputs until the mapping is independently sealed.
7. Perturb hDeltaC, hDeltaG, PFL3 output, and the frozen hDeltaM comparator. Run the mandatory PFNp_b low-confidence transmitter sensitivity case.
8. Seal actual odor -> FB5AB and body-frame wind -> PFN input transforms from literature/topography, not task score.
9. Run intact versus degree-preserving rewires with identical compute and frozen train/validation/final seeds.
10. Promote the renderer to Release B only after held-out behavioral qualification passes.

## E002b principles to freeze before running it

E002b should answer a mechanistic question, not a game-score question:

> Does an independently signed, body-ID-resolved MaleCNS candidate integration scaffold propagate controlled upstream perturbations through the frozen hDeltaG relay into the already-audited steering layer in the expected reproducible manner?

Required properties:

- deterministic replay;
- exact authority hashes recorded in the result;
- no source coordinate or culprit role anywhere in the graph;
- fixed hDeltaG primary relay and hDeltaM comparator;
- results reported at structural thresholds 1, 3, 5, and 10;
- no threshold selected by downstream task performance;
- hDeltaG lesion must block the hDeltaG-only candidate route rather than be compensated by arbitrary model freedom;
- PFL3-output cut remains a terminal negative control;
- PFNp_b-sign-zero sensitivity reported separately;
- partial-lesion response magnitude stays descriptive while the current rate model normalizes incoming weights.

## Visual acceptance tests

The renderer should fail CI if any of these regress:

- render changes simulation/recording state;
- output frame dimensions are not exactly the requested dimensions;
- a displayed graph authority hash does not match the recording/manifest;
- named modeled activity is requested without recorded neural state;
- `MEASURED CONNECTIVITY` and `MODELED ACTIVITY` labels are absent when both are shown;
- exact plume rendering is requested from an incomplete plume snapshot;
- the culprit location differs from the simulated source;
- a development recording loses its development claim badge;
- source coordinates or culprit identity appear in controller inputs;
- a real-vs-rewire headline is enabled before the qualification manifest permits it.

## Public-language contract

Strongest current public-safe wording:

> We found a body-ID-resolved candidate route in the MaleCNS connectome that structurally links literature-motivated odor/wind integration populations to a steering network. The steering propagation model passes its isolated deterministic perturbation checks. Full odor-navigation behavior is still being qualified.

Future qualified wording, only if the final experiment supports it:

> We gave the MaleCNS-constrained model the same odor-navigation task, then degree-preserving scrambled its wiring. The intact wiring performed better on frozen held-out episodes.

The second sentence is the viral result we want. The entire engineering plan exists to earn it rather than animate it prematurely.
